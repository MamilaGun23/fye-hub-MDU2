## Interview prompts

| Question | Evidence to prepare |
| --- | --- |
| What did you personally own? | Explain feature decisions, implementation direction, and the controls you defined. Acknowledge collaborators and original attribution. |
| Why four roles? | Walk through the distinct tasks of a student, mentor, supervisor, and administrator. |
| What was technically challenging? | Choose a workflow you know in depth and explain its interface, database function, permission rules, failure cases, and tests. |
| How is access enforced? | Distinguish browser routing from database RLS/function/storage policies. Do not claim production security validation without evidence. |
| What would you change? | Explain the missing baseline schema, global module coupling, live permission checks, and accessibility review. |
| What impact did it have? | Describe delivered capabilities. No adoption, retention, or satisfaction results have been measured in this presentation. |
